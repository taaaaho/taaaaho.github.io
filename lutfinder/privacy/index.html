LUT Finder が扱うデータと、その利用・保存・削除について。

最終更新日：2026年10月28日

運営者

運営者：Takaho Hayashi（LUT Finder の開発者）
お問い合わせ：appfactorycloud@gmail.com

基本方針

LUT Finder は、撮影・LUT の適用・写真の書き出しをすべて iPhone の中で行います。アプリには通信の機能がなく、写真、映像、取り込んだ LUT、設定、利用状況などを開発者や第三者のサーバーへ送信することはありません。アカウントの作成もありません。

カメラ

ファインダーの表示と撮影のためにカメラを使います。ファインダーの映像は表示・ヒストグラム・LUT のサムネイルを作るためにその場で処理するだけで、保存しません。保存するのは、利用者がシャッターを押して撮った写真だけです。

写真ライブラリ

  • 写真の追加：撮った写真（RAW と LUT を当てた写真）を写真ライブラリに保存するために使います。
  • 写真の書き換え：撮影直後の確認画面で露光量を「写真に反映」したときだけ、その写真を書き換えるために写真ライブラリへのアクセスを求めます。書き換えるのはアプリで撮った写真だけで、ほかの写真を読み取ったり送信したりすることはありません。書き換えは写真アプリの「元に戻す」で取り消せます。

アプリは位置情報の利用を求めず、アプリが写真に位置情報を加えることはありません。

取り込んだ LUT・プロファイル

利用者が選んだ .cube・.xmp・DNG プロファイルのファイルを読み込み、LUT としてアプリの保存領域に保存します。元のファイルは変更しません。

動きのセンサー

水準器を表示している間だけ、iPhone の傾きを知るためにモーションセンサーの値を使います。値はその場で表示に使うだけで、保存も送信もしません。

設定

選んだ LUT・適用量・保存形式・補助表示などの設定は、iPhone の中に保存します。iPhone のバックアップの設定によっては、アプリのデータ（取り込んだ LUT と設定）が iCloud などのバックアップに含まれることがあります。

解析・広告・トラッキング

利用解析、広告、トラッキングの機能や SDK は使っていません。現行バージョンにアプリ内購入はありません。

保存期間と削除

撮った写真は写真アプリに保存され、利用者が削除するまで残ります。取り込んだ LUT はアプリの一覧から削除でき、アプリを削除すると LUT と設定はすべて消えます（写真アプリに保存した写真は残ります）。

お問い合わせで受け取る情報

メールでお問い合わせいただいた場合、送信元のメールアドレスと本文、任意でお送りいただいた端末・アプリの情報や写真を、回答と不具合の確認のためだけに使います。お問い合わせ内容の削除をご希望の場合も、上記の窓口へご連絡ください。

サポートサイト

本サイトは GitHub Pages で配信しています。独自のアクセス解析、広告、トラッキングのスクリプト、問い合わせフォームは設置していません。閲覧時の通信情報は、配信事業者である GitHub が同社のプライバシーステートメントに基づいて取り扱います。
